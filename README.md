# Палки и Балки — сайт ателье мебели (Москва)

Премиальный тёмный лендинг + страница портфолио. Без сборки и зависимостей:
два самодостаточных HTML-файла (стили и скрипты внутри), картинки рядом.

## Структура

```
index.html            главная: герой с надписью за кухней → о компании → преимущества →
                      направления (витрина с фото) → производство → портфолио →
                      блок с цифрой → FAQ → бесплатный замер с квизом → контакты
portfolio.html        портфолио: фильтр по направлениям, просмотр фото
img/source/kitchen.png исходное фото клиента
img/hero-bg.jpg       фон героя (апскейл исходника)
img/hero-front.webp   передний план с прозрачностью — им перекрывается надпись
img/shot-*.jpg        кадрировки исходника для секций
img/shots/*.svg       плейсхолдеры для направлений, где фото ещё нет
tools/prep_photos.py  готовит слои героя из исходного фото
tools/gen_assets.py   плейсхолдеры, фавикон, og и SVG-спрайт иконок
```

## Запуск

```bash
npm run dev          # → http://localhost:4173
```

Скрипт поднимает `serve` через npx, ставить ничего не нужно. Без Node:

```bash
npm run serve:python # то же самое на python, порт тот же
# или
python3 -m http.server 4173
```

Сборки нет: HTML отдаётся как есть, поэтому Vite/webpack не нужны —
правку в файле видно после обычного обновления страницы.

## Один файл для быстрого деплоя

```bash
npm run build:single     # → dist/palki-i-balki.html (~0,7 МБ)
```

Скрипт перекодирует фотографии в WebP, вшивает их и SVG-заглушки как
`data:URI`, переводит ссылки на `portfolio.html` на внутреннюю секцию
`#portfolio` и убирает `og:image` (соцсети не читают data:URI).
Получается файл без единой внешней зависимости, кроме шрифта с Google Fonts —
его можно перетащить в Vercel Drop, отправить в мессенджере или открыть
двойным кликом.

Ограничения однофайловой сборки: только главная страница (второй страницы
в одном файле быть не может) и нет картинки для превью в соцсетях.
Нужен полный сайт с портфолио — деплойте папку целиком.

## Палитра

| Роль | Цвет |
|---|---|
| Графит (тёмные секции) | `#1E1C1A` |
| Холст страницы | `#141312` |
| Светлые секции | `#E8E7E5` |
| Тёплый greige (акценты, подписи) | `#B8AD9F` |
| Тёмное дерево (ховер кнопки «Меню») | `#5A3F33` |
| Текст на тёмном / на светлом | `#F2EFEA` / `#1A1A1A` |

Секции — крупные скруглённые карточки (радиус 40px, на телефоне 28px) с зазорами
на общем холсте; тёмные и светлые чередуются.

## Как устроен главный экран

Три слоя друг за другом:

1. `img/hero-bg.jpg` — фон, затемнён фильтром и градиентом;
2. надпись «ПАЛКИ / и БАЛКИ» — **между** слоями, поэтому уходит за мебель;
3. `img/hero-front.webp` — остров и каменная столешница с прозрачностью.

Оба слоя выводятся с одинаковыми `object-fit: cover` и `object-position: 50% 55%`,
иначе стык разъедется. Скрипт считает, где именно проходит кромка столешницы
(та же математика, что у браузера при кадрировании), и опускает надпись так,
чтобы за мебель ушла ровно четверть высоты букв — одинаково на любом экране.
Константы в начале блока параллакса: `EDGE`, `DIP`, `BASE`, `--hero-zoom`.

Анимации: буквы выезжают по очереди с задержкой 40 мс, при скролле «ПАЛКИ»
уходит влево, «и БАЛКИ» вправо, надпись растёт и растворяется, кухня
переднего плана увеличивается до 1.15 и отстаёт от контента. Всё отключается
при `prefers-reduced-motion`.

## Фотографии

**Исходник маленький — 433×325.** Для полноэкранного героя это мало: скрипт
поднимает его до 1732×1300 с резкостью и зерном, но на большом мониторе мягкость
заметна. Пришлите оригинал в полном разрешении и перегенерируйте:

```bash
python3 tools/prep_photos.py
```

Про автоматический вырез: `rembg` (модели `u2net` и `isnet-general-use`) на этом
кадре оставляет меньше 1% изображения — на интерьерном снимке нет «объекта»,
который он умеет выделять. Поэтому маска переднего плана задана вручную кромкой
столешницы (константа `EDGE` в `tools/prep_photos.py`, координаты исходника 433×325).
Если пришлёте готовый вырез — положите его как `img/hero-front.webp`, разметку
менять не нужно.

Остальные фото: `img/shot-*.jpg` — кадрировки того же кадра, `img/shots/*.svg` —
рисованные заглушки. Меняются простой заменой `src` в разметке.

## Что заменить перед публикацией

| Что | Как искать | Статус |
|---|---|---|
| Telegram | `PR0_XBOCT` | ✅ ваш, менять не нужно |
| Телефон | `+7 (999) 000-00-00` и `79990000000` | заглушка |
| Адрес и часы | `Складочная` | заглушка |
| Домен в мета-тегах | `palki-i-balki.ru` | заглушка |
| Цифры «11 лет», «3 000+», «700+» | секция `id="about"`, блок `bignum` | **взяты с референса, поставьте свои** |
| Гарантия 10 лет, сроки, предоплата | секция преимуществ, FAQ | проверьте под свои условия |
| Цены «от …» | блок `dirs` | заглушки |
| Фото в карточках направлений | секция `id="napravleniya"` | заглушки, кроме кухни |
| Фото цеха и станков | секция `id="production"` | **заглушка — нужны ваши фото производства** |
| Точность 0,1 мм, ЧПУ, кромка ПУР | секция `id="production"` | проверьте под своё оборудование |
| Описания проектов | `portfolio.html` | заглушки |
| Карта | секция `id="contacts"` | стилизованная заглушка со ссылкой на Яндекс.Карты — замените на встраиваемую карту |

Telegram для квиза берётся из атрибута `data-tg` у `<body>` — он есть в обоих файлах.

## Квиз и лид-магнит

Посетитель отмечает направления и бюджет, скрипт собирает текст и открывает
`https://t.me/PR0_XBOCT?text=…` — сообщение уже готово, отправку подтверждает
человек. Рядом — копирование текста в буфер. Сервер не нужен, данные с сайта
никуда не уходят.

## Анимации и прокрутка

- Появление секций и очередь карточек — `IntersectionObserver`, задержка 70 мс
  между соседними карточками; заголовки открываются шторкой (`clip-path`).
- Фотографии в крупных блоках (`.par`) едут параллаксом, геометрию меряем
  на ресайзе, а не в кадре — иначе браузер пересчитывает раскладку и всё дёргается.
- Весь скролл идёт через один кадровый цикл (`jobs` в скрипте): сначала читаем
  позицию, потом пишем трансформы.
- Плавное пролистывание колесом — собственная инерция с шагом по времени
  (`RATE = 13`, доезжает примерно за 0,4 с). Включается только при мыши
  (`pointer: fine`): на тач-экранах своя инерция лучше. При этом скрипт
  переключает `scroll-behavior` на `auto` — иначе браузерная плавность
  дерётся с собственной и прокрутка вязнет.
- Число в блоке с цифрой набегает счётчиком (`data-count`).
- Всё отключается при `prefers-reduced-motion: reduce`.

## Заметки по коду

- Два файла самодостаточны намеренно: каждый можно открыть или перенести
  отдельно. Плата за это — дублирование токенов и шапки; при добавлении третьей
  страницы стили стоит вынести в общий `css/`.
- Спрайт иконок вставляется генератором между маркерами
  `<!--SPRITE:START-->` и `<!--SPRITE:END-->`: после правок в `tools/gen_assets.py`
  запустите его снова.
- Доступность: меню, FAQ, фильтры и просмотр фото работают с клавиатуры,
  закрываются по `Esc`; анимации выключаются системной настройкой.
- Шрифт Manrope подключён с Google Fonts. Нужна независимость от CDN — скачайте
  в `fonts/` и замените `<link>` на локальный `@font-face`.
