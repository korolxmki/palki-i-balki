# Палки и Балки — лендинг ателье мебели (Москва)

Статический сайт без сборки: чистый HTML, CSS и JavaScript. Открывается двойным
кликом по `index.html`, разворачивается на любом хостинге или GitHub Pages.

## Структура

```
index.html            главная: hero → направления → блоки направлений → портфолио →
                      процесс → преимущества → отзывы → квиз → контакты
portfolio.html        портфолио с фильтром по направлениям и просмотром фото
css/styles.css        все стили (токены → база → компоненты → секции → адаптив)
js/main.js            меню, аккордеон, квиз, фильтры, лайтбокс
img/shots/*.svg       ПЛЕЙСХОЛДЕРЫ фотографий — заменить на реальные снимки
img/favicon.svg       фавикон
img/og.svg            картинка для соцсетей
tools/gen_assets.py   генератор плейсхолдеров и SVG-спрайта иконок
```

## Как посмотреть локально

```bash
python3 -m http.server 8000
# открыть http://127.0.0.1:8000
```

## Что обязательно заменить перед публикацией

Всё перечисленное — заглушки. Проще всего пройтись поиском по всем файлам.

| Что | Как искать | Где встречается |
|---|---|---|
| Telegram-аккаунт | `palki_i_balki` | `data-tg` у `<body>`, ссылки в шапке, меню, квизе, подвале, мобильной панели |
| Номер WhatsApp | `79990000000` | `data-wa` у `<body>`, ссылки `wa.me` и `tel:` |
| Телефон для показа | `+7 (999) 000-00-00` | шапка, меню, квиз, подвал |
| Почта | `hello@palki-i-balki.ru` | подвал, JSON-LD |
| Адрес и часы работы | `Складочная` | меню, подвал, JSON-LD |
| Домен в мета-тегах | `palki-i-balki.ru` | `canonical`, `og:url` в обоих файлах |
| Цены «от …» | `от 250 000 ₽` и т.п. | плитки направлений и заголовки аккордеона |
| Сроки, гарантия, условия | `Гарантия 3 года`, `Предоплата 50%` | hero, преимущества, блок процесса |
| **Отзывы** | секция `id="otzyvy"` | **демо-тексты, заменить на реальные отзывы клиентов** |
| **Проекты в портфолио** | `portfolio.html` | демо-описания: метраж, материалы, сроки |

Telegram и WhatsApp в квизе берутся **только** из `data-tg` / `data-wa` у `<body>` —
достаточно поменять их в двух файлах (`index.html`, `portfolio.html`).

## Фотографии

В `img/shots/` лежат сгенерированные SVG-заглушки (по 3 на каждое направление).
Заменить можно двумя способами:

1. положить реальные файлы с теми же именами (`kitchen-1.svg` → `kitchen-1.jpg`)
   и поправить `src` в разметке;
2. или сразу записать свои пути в `<img src="...">`.

Рекомендуемый размер — от 1600 px по длинной стороне, соотношение 4:3, формат
WebP или JPEG. Атрибуты `loading="lazy"`, `width` и `height` лучше сохранить:
они убирают «прыжки» вёрстки при загрузке.

Перегенерировать заглушки и спрайт иконок (после правок в `tools/gen_assets.py`):

```bash
python3 tools/gen_assets.py
```

Скрипт переписывает `img/shots/*`, `img/favicon.svg`, `img/og.svg` и вставляет
спрайт иконок между маркерами `<!--SPRITE:START-->` и `<!--SPRITE:END-->`
в обеих HTML-страницах.

## Как работает квиз

1. Посетитель отмечает направления (можно несколько) и бюджет, по желанию — имя.
2. Скрипт собирает текст заявки и показывает его в блоке предпросмотра.
3. Кнопка открывает `https://t.me/<аккаунт>?text=<текст>` — в Telegram
   подставляется готовое сообщение, отправку подтверждает сам посетитель.
   Рядом те же данные можно отправить в WhatsApp или скопировать в буфер.

Данные никуда не отправляются с сайта: серверная часть не нужна, а значит,
не нужны и согласия на обработку на стороне сайта. Если позже появится
back-end-форма — не забудьте про политику обработки персональных данных
(сейчас ссылка в квизе ведёт на блок контактов, её стоит заменить на
отдельную страницу).

## Публикация на GitHub Pages

Settings → Pages → Source: `Deploy from a branch`, ветка с сайтом, папка `/ (root)`.
Отдельная сборка не требуется.

## Совместимость и доступность

- Адаптив: 1440 / 1100 / 860 / 640 px, мобильная панель с кнопкой заявки.
- Клавиатура: меню, аккордеон, фильтры и лайтбокс управляются с клавиатуры,
  лайтбокс и меню закрываются по `Esc`.
- Учитывается `prefers-reduced-motion`: анимации и плавный скролл отключаются.
- Шрифт Manrope подключён с Google Fonts. Если нужна независимость от внешних
  CDN — скачайте шрифт в `fonts/` и замените `<link>` на локальный `@font-face`.
